## Software

Some software and tools I use:

- **Firefox** and **Chromium** for browsing
- **Bitwarden** for password management
- **VS Code (OSS)** and **Neovim** for coding
- **Alacritty** as a terminal emulator
- **Zsh** (with **Oh My Zsh**) as a shell environment
- **Tmux** as a terminal multiplexer
- **GNU Stow** for managing dotfiles

I've used **GNU/Linux** as my operating system since 2016. See [dotfiles](https://github.com/themaxgam/dotfiles) for system configuration details.
