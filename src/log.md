This site is built with the **11ty** static site generator and styled with custom stylesheets using **SASS**.
Content is managed through **Markdown** files, utilizing **Nunjacks** as the template engine.
The entire project is deployed and hosted on **GitHub Pages** via **GitHub Actions**.

This project is **open-source**. See the source code [here](https://github.com/themaxgam/web).

Unless otherwise noted, all content is generated by a human.
